# Mira Contest Final Template

Copy `main.tex` to `paper/main.tex` and `references.bib` to
`paper/references.bib`. The canonical build command is:

```powershell
python <mira-skill>/scripts/contest_final_pipeline.py --root <project-root>
```

The template deliberately does not pad the paper to the required body length.
The final audit accepts 23--30 effective body pages only when those pages contain
real derivation, results, validation, visual evidence, error analysis, and model
generalization.
