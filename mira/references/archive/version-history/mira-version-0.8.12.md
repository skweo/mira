# Mira 0.8.12

## Scope

Mira 0.8.12 adds Mermaid sequence-diagram templates for interaction-order
visuals.

Use them when a paper needs to show who interacts with whom, in what order, and
where activation, branch, feedback, or network boundaries occur.

## Template

- `assets/templates/mermaid_sequence_diagram.mmd`
- Reference rules: `references/mermaid-diagram-templates.md`

## Routing

When the request or artifact mentions Mermaid, `sequenceDiagram`, sequence
diagram, interaction order, call chain, human gate interaction, or时序图, route
the Mermaid template rules before drawing or auditing diagrams.
