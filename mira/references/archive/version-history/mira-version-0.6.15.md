# Mira 0.6.15

## Scope

Mira 0.6.15 adds a PPT-editable multi-branch feature-fusion architecture
diagram pattern. It targets figures with multi-source inputs, parallel feature
extractors, latent vectors, attention/fusion modules, auxiliary reconstruction
paths, and prediction or decision heads.

## Added

- `references/multimodal-fusion-architecture-rules.md`
- `plot_ppt_reasoning_diagram.py --demo multimodal_fusion`
- routing triggers for multimodal/fusion/attention/architecture figure requests

## Contest-Paper Rule

Use this figure only when the branches are real model objects. The diagram must
be paired with formulas, training settings, baseline/ablation, validation
metrics, or a clear waiver. A fusion architecture diagram is paper logic, not
numerical evidence by itself.
