# 蒙特卡洛模拟

## 一句话

蒙特卡洛 = **用大量随机采样来逼近一个没法直接算的答案**。积分算不出来？扔十万个点下去数。概率模型太复杂？抽一万次随机路径看结果分布。

## 适用场景

| 场景 | 例子 |
|------|------|
| 求解复杂定积分 | $\int_0^1 \sin(x^2) dx$——解析不可解 |
| 模拟随机系统 | 排队系统——顾客到达时间随机、服务时间随机 |
| 灵敏度/不确定性分析 | 参数有分布→结果是什么分布？ |
| 优化问题 | 模拟退火——随机在搜索空间中跳 |
| 风险评估 | 投资收益的概率分布 |

## 经典案例：用蒙特卡洛求 $\pi$

```python
import numpy as np

N = 1000000
x = np.random.uniform(-1, 1, N)
y = np.random.uniform(-1, 1, N)
inside = (x**2 + y**2) <= 1
pi_est = 4 * np.sum(inside) / N
print(f"π ≈ {pi_est:.6f} (误差: {abs(pi_est - np.pi):.6f})")
```

> 原理：正方形面积 4，内切圆面积 $\pi$。随机撒点 → 落圆内的比例 ≈ $\pi/4$。

## 蒙特卡洛积分的误差

误差与 $\sqrt{N}$ 成反比：

$$\text{error} \propto \frac{1}{\sqrt{N}}$$

- 10,000 次 → 1% 误差
- 1,000,000 次 → 0.1% 误差
- 要提高一位精度，需要 100 倍的计算量

## 实际建模中的用法

```python
import numpy as np
import matplotlib.pyplot as plt

def monte_carlo_simulation(model_func, param_distributions, N=10000):
    """
    model_func: 模型函数 f(params) → result
    param_distributions: {参数名: (分布函数, 参数)}
    N: 模拟次数
    """
    results = np.zeros(N)
    for i in range(N):
        params = {}
        for name, (dist, args) in param_distributions.items():
            params[name] = dist(*args)
        results[i] = model_func(**params)

    return {
        'mean': np.mean(results),
        'std': np.std(results),
        'percentile_5': np.percentile(results, 5),
        'percentile_95': np.percentile(results, 95),
        'histogram': results
    }

# 示例：排队系统
# 顾客到达间隔 ~ exp(λ=2)，服务时间 ~ N(μ=5, σ=1)
result = monte_carlo_simulation(
    model_func=lambda arrival, service: max(service - arrival, 0),
    param_distributions={
        'arrival': (np.random.exponential, (2.0,)),
        'service': (np.random.normal, (5.0, 1.0))
    },
    N=50000
)
```

## 减小方差的技巧

| 技术 | 原理 |
|------|------|
| 对偶变量（antithetic variates） | 每次同时用随机数和它的"对称"（1-U）——正负偏差抵消 |
| 控制变量（control variates） | 找一个和原问题强相关且有解析解的问题——算两者的差 |
| 重要性采样（importance sampling） | 不是均匀撒点——在"重要"的区域多撒点 |

## 常见陷阱

- N 太小：100 次不够——至少 10,000 次起步
- 没有说清楚随机数种子——审稿人复现不了
- 分布假设写在暗处——参数服从什么分布，必须要明确的假设

## 竞赛论文深度要求

- 说明随机变量、分布、参数来源和独立性假设。
- 固定随机种子，并记录模拟次数。
- 报告均值、标准差、置信区间或分位数，而不是只给一个点估计。
- 做模拟次数收敛检查，证明结果不是小样本随机波动。
- 对关键分布参数做敏感性分析。
- 若用于排队、风险或系统仿真，给出代表性样本路径或状态指标表。
- 结果表述为“模拟估计”或“在假设分布下的估计”，不要写成确定性真实值。
