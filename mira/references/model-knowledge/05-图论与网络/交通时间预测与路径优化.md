# Model Card: 交通时间预测与路径优化

## Use When

- 题目给出传感器速度、流量、路段长度、路况等级或交通网络图。
- 需要估计行车时间、判断拥堵状态、选择最优路线或给出可靠时间区间。
- 路径选择依赖预测边权，而不是固定距离。

## Avoid When

- 路段权重已经确定且无时间变化，直接用最短路即可。
- 没有速度、流量、距离、路况等级等可支撑边权估计的数据。
- 无法定义“最优”是最短时间、最短距离、最低风险还是广义费用。

## Typical Contest Tasks

- 交通时间预测。
- 路径规划。
- 随机网络最短路。
- 导航系统改进。
- 交通拥堵分析。

## Variables and Parameters

| Symbol | Type | Meaning | Unit | Source or estimation |
|---|---|---|---|---|
| `l_ij` | parameter | 边 `(i,j)` 长度 | distance | 题目或地图 |
| `v_i(t)` | data | `t` 时刻传感器速度 | distance/time | 观测 |
| `T_ij(t)` | variable | 边 `(i,j)` 行车时间 | seconds/minutes | 速度/流量模型 |
| `sigma_ij` | parameter | 边时间标准差 | time | 样本统计或估计 |
| `w` | parameter | 广义费用权重 | none | 偏好/题意/敏感性 |

## Core Formulation

基础边时间可由速度模型给出：

```text
T_ij(t) = 2 l_ij / (v_i(t) + v_j(t))
```

若考虑流量滞留，将总时间拆为：

```text
T_ij(t) = free_flow_time_ij(t) + delay_time_ij(t)
```

广义费用可写成：

```text
C_ij(t) = w_1 normalized_time_ij + w_2 normalized_length_ij + w_3 normalized_variance_ij
```

在非负边权下，用 Dijkstra 或其他最短路算法求：

```text
route* = argmin sum C_ij(t)
```

若考虑可靠性，报告路径时间均值、方差和概率约束下的时间上界。

## Solver or Implementation Route

- Preferred language: Python or MATLAB.
- Recommended packages: `pandas`, `numpy`, `networkx`, `scipy`, `matplotlib`.
- Data preprocessing: unit conversion, edge direction check, missing speed/flow处理, peak/off-peak split.
- Baseline: distance shortest path or speed-only travel-time model.
- Runtime notes: correlation-aware route comparison may require candidate path enumeration; large networks should use k-shortest paths or scenario simulation.

## Validation

- Feasibility check: final path adjacent nodes must all be connected with correct direction.
- Sensitivity check: vary generalized-cost weights and congestion thresholds.
- Baseline comparison: compare against shortest-distance or speed-only route.
- Error or uncertainty check: report prediction-vs-actual error, standard deviation, confidence/probability interval, or scenario range.

## Paper Writing Notes

- 先诊断交通状态，再说明预测算法，最后做路径优化。
- “最优路线”必须在公式前定义清楚。
- 最终答案写成节点序列和时间/风险表，不要埋在段落中。
- 如果预测边权来自模型，必须先验证或至少给出误差/方差。

## Common Pitfalls

- 把所有边都按起点出发时刻计算，忽略车辆到达下游边的递推时间。
- 只给路线图，不给路径表和目标值。
- 未说明边权单位或方向。
- 用 Dijkstra 求解含负权或非加性风险目标。
- 只报告平均时间，不报告高峰期不确定性。
