# Model Card: 出租车供需与价格规划

## Use When

- 题目要求预测出租车需求、确定出租车数量、评价空驶率或制定价格方案。
- 问题同时涉及乘客、司机、城市管理、资源/环境等多方利益。
- 题目要求数据采集方案、管理建议、短文或政策类输出。

## Avoid When

- 只需要简单供需描述，不需要数量规划或价格决策。
- 缺少人口、出行总量、出行方式、运营时间、速度、距离、费用等关键输入，且无法合理假设。
- 不能解释价格变化如何影响需求或空驶率。

## Typical Contest Tasks

- 需求预测。
- 服务容量规划。
- 价格优化。
- 综合评价。
- 管理建议。
- 数据采集方案。

## Core Formulation

可先由出行总量和方式分担得到出租车需求：

```text
taxi_trips = total_trips * taxi_mode_share
loaded_distance_total = taxi_trips * average_trip_distance / passengers_per_trip
```

再由空驶率和运营能力估算实际运营车辆：

```text
N_working = loaded_distance_total / (operating_time * average_speed * (1 - vacancy_rate))
```

定价问题可用候选方案评价或约束优化：

```text
maximize stakeholder_score(passenger_cost, driver_income, vacancy_rate, environment)
subject to passenger_cost <= acceptable_cost
           driver_income >= minimum_income
           fare parameters are practical
```

## Solver or Implementation Route

- Preferred language: Python for reproducible tables and plots; MATLAB acceptable for legacy examples.
- Recommended packages: `pandas`, `numpy`, `scipy.optimize`, `matplotlib`.
- Data preprocessing: population categories, OD/mode-share consistency, unit conversion, missing-value audit.
- Baseline: current fleet/current fare/current vacancy-rate scheme.
- Runtime notes: if using AHP, store judgment matrices and consistency ratios; if using neural networks, store training samples and validation error.

## Validation

- Feasibility check: fleet size, operating vehicles, trip demand, and vacancy-rate units must close.
- Sensitivity check: vary vacancy-rate target, average distance, passenger per trip, elasticity, and fuel price.
- Baseline comparison: compare recommended scheme against current fleet/fare.
- Error or uncertainty check: forecast error, scenario range, or city-analogy caveat.

## Paper Writing Notes

- 按官方问题组织：需求预测、数量规划、价格方案、数据采集、管理建议。
- 每个政策结论必须绑定一个数值表或可行性审计。
- 对“类比城市”“经验目标”“价格弹性”这类外部假设要写来源和敏感性。
- 管理短文应放在技术模型之后，语言面向管理部门，但引用模型结果。

## Common Pitfalls

- 只预测乘车人数，不把它转换成车辆供给能力。
- 用单一“最优数量”但不说明空驶率、等待或服务水平。
- 把 AHP 权重当成事实，不做一致性或敏感性。
- 使用神经网络但没有样本范围和误差说明。
- 遗漏题目要求的数据采集方案或管理短文。
