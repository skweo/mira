# 数学建模问题类型与选方法

## 一句话

拿到题目先分类，再选方法。分类错了，后面全白做。

## 问题类型速查表

| 题目关键词 | 问题类型 | 首选方法 | 备选方法 |
|------|------|------|------|
| 最大利润、最小成本、最优分配 | **优化问题** | 线性规划 / 整数规划 | 非线性规划、动态规划 |
| 产销、供需、调运、成本矩阵、多源多汇分配 | **运输问题/供需分配** | 运输问题 / 最小费用流 / LP | 整数规划、预测-优化 |
| 资源配置、产能、名额、预算、配额、调度、分配方案 | **数据驱动优化/资源配置** | LP/MILP/运输问题/目标规划 + 数据审计 | 预测-优化、评价-优化、启发式搜索 |
| 排名、评分、选择方案 | **评价问题** | AHP / TOPSIS | 模糊综合评价、熵权法 |
| 预测、趋势、未来 | **预测问题** | 时间序列 / 回归 | 灰色预测 GM(1,1)、神经网络 |
| 标定、校准、反推参数、辨识、反演、检测数据 | **参数辨识/反问题** | 正向模型 + 最小二乘/搜索 | 非线性优化、贝叶斯估计、灵敏度分析 |
| 路径、网络、配送 | **图论/网络** | 最短路径 / 网络流 | 遗传算法、模拟退火 |
| 多阶段、状态转移、库存、生产存储、剩余资源 | **动态规划/阶段决策** | 动态规划 | MILP、贪心基线、启发式搜索 |
| 变化率、传播、生长 | **微分方程** | ODE 建模 | 差分方程、元胞自动机 |
| 概率、随机、风险 | **概率统计** | 假设检验 / 贝叶斯 | 蒙特卡洛、马尔可夫链 |
| 多目标冲突 | **多目标决策** | 目标规划 / 分层序列 | 进化算法（NSGA-II） |
| 缺失值、插值、重采样、空间场、栅格、任意截面、等值线 | **数值插值/空间重建** | 线性/三线性插值、样条、RBF、克里金 | 边缘保持/分段插值、局部回归 |
| 芯片、DSP、ASIC、FPGA、定点、位宽、吞吐、资源、时延、流水线、仿真平台 | **工程算法仿真与资源权衡** | 浮点基线 + 参数扫描 + 定点/资源模型 | 网格搜索、多目标权衡、近似替代、自动设计规则 |

## 判断流程

```
读到题目
  → 有明确的目标函数（最大化/最小化）？
    → YES → 优化问题 → 线性/非线性/整数规划
    → NO → 下面
  → 有多源多汇、供需平衡、成本矩阵或调运分配？
    → YES → 运输问题 / 最小费用流 / LP
    → NO → 下面
  → 有阶段、状态、转移、库存或剩余资源？
    → YES → 动态规划 / 阶段决策
    → NO → 下面
  → 需要从多个选项中选出最好的？
    → YES → 评价问题 → AHP / TOPSIS
    → NO → 下面
  → 需要用过去的数据推未来？
    → YES → 预测问题 → 回归 / 时间序列 / GM(1,1)
    → NO → 下面
  → 需要根据检测/实验数据反推参数、标定表或校准模型？
    → YES → 参数辨识 / 反问题
    → NO → 下面
  → 有"变化率"、"传播速度"、"增长速度"？
    → YES → 微分方程
    → NO → 下面
  → 有节点、边、路径、网络？
    → YES → 图论
    → NO → 下面
  → 需要估计采样点之间的位置、补全空间/时间网格、重采样或重建曲面？
    → YES → 数值插值 / 空间重建
    → NO → 下面
  → 题目要求算法可实现，并给出芯片/硬件/定点/吞吐/资源约束？
    → YES → 工程算法仿真与资源权衡
    → NO → 下面
  → 有随机因素、不确定性需要量化？
    → YES → 概率统计 / 蒙特卡洛
```

## 常见组合

很多题目不是一个类型——是多个：

| 题目 | 主类型 | 子类型 |
|------|------|------|
| "选择最优配送路线并预测需求量" | 图论（路径） | 预测（需求量） |
| "评价各方案优劣并给出最优资源配置" | 评价 | 优化 |
| "在产能和配额限制下分配资源以提高收益" | 数据驱动优化/资源配置 | 预测 / 评价 / 整数规划 |
| "从多个仓库向多个需求点调运物资" | 运输问题/供需分配 | 最小费用流 / 整数规划 |
| "按月份安排生产、库存和销售" | 动态规划/阶段决策 | 线性规划 / 库存模型 |
| "根据检测数据确定变位参数并给出标定表" | 参数辨识/反问题 | 几何/物理正向模型 / 非线性最小二乘 |
| "预测传染病传播并评估防控措施" | 微分方程 | 评价 |
| "根据离散监测点重建污染空间分布并制定治理方案" | 数值插值/空间重建 | 评价 / 优化 |
| "设计满足性能门限且资源最低的芯片算法" | 工程算法仿真与资源权衡 | 仿真 / 多目标优化 / 定点量化 |

## 注意事项

- 不要看到"最优"就立刻线性规划——先看约束和目标函数是不是线性的
- 历年题型-方法表只能用来启发检索；当前题目的变量、目标、约束、数据和评价指标才决定方法
- 有供给、需求和单位成本矩阵时，优先检查运输问题或最小费用流，不要直接套启发式算法
- 有阶段状态转移时，先定义阶段、状态、决策、转移和边界，再判断能否用动态规划
- 有标定、校准、辨识、反演时，先建立正向模型，再定义原始数据中的真实拟合目标；不要把显示值、旧模型值或派生量误当实测目标
- 资源配置题先抓三件事：目标函数由哪些收益/成本构成，硬约束有哪些，决策变量的粒度是什么
- 数据丰富不等于全都要用；必须说明哪些附件/字段进入模型，哪些被忽略，以及是否存在重复计入同一信息
- 数据少于 10 个点 → 灰色预测比时间序列靠谱
- 有主观判断（专家打分）→ AHP 天生适合
- 插值结果不是实测值；必须说明坐标单位、采样间隔、边界/外推策略，并尽量做留出点或仿真误差验证
- 工程实现题不能只报最优资源；必须先证明性能达标，再从操作次数、位宽、吞吐、延迟等约束逐项审计资源
