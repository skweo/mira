# TOPSIS 逼近理想解排序

## 一句话

TOPSIS = 哪个方案离"最好的可能"最近、离"最差的可能"最远，谁排第一。全数据驱动——不需要专家打分。

## 与 AHP 对比

| | AHP | TOPSIS |
|------|------|------|
| 权重来源 | 专家两两比较（主观） | 数据自带（客观，如熵权法）或给定 |
| 需要多少数据 | 只需要专家判断 | 需要各方案在各指标上的**数值** |
| 适合 | 定性判断多、数据少 | 定量数据多、指标单位不统一 |

## 算法步骤

### 1. 构建原始矩阵 + 归一化

$n$ 个方案，$m$ 个指标 → 矩阵 $\mathbf{X}_{n \times m}$。

归一化（向量归一化）：

$$
z_{ij} = \frac{x_{ij}}{\sqrt{\sum_{k=1}^{n} x_{kj}^2}}
$$

### 2. 构建加权归一矩阵

给定权重 $w_j$（$\sum w_j = 1$）：

$$
v_{ij} = w_j \cdot z_{ij}
$$

### 3. 确定正理想解和负理想解

- 正理想解 $A^+$：每个指标取**最好**的值（效益型取 max，成本型取 min）
- 负理想解 $A^-$：每个指标取**最差**的值

### 4. 计算距离

$$
D_i^+ = \sqrt{\sum_{j=1}^{m} (v_{ij} - A_j^+)^2}
$$

$$
D_i^- = \sqrt{\sum_{j=1}^{m} (v_{ij} - A_j^-)^2}
$$

### 5. 计算相对贴近度 + 排序

$$
C_i = \frac{D_i^-}{D_i^+ + D_i^-}
$$

$C_i$ 越大 → 方案越接近正理想解 → 排名越前。

## Python 实现

```python
import numpy as np

def topsis(X, weights):
    """X: n×m 原始矩阵, weights: m 个权重"""
    n, m = X.shape
    # 归一化
    Z = X / np.sqrt(np.sum(X**2, axis=0))
    # 加权
    V = Z * weights
    # 正负理想解
    A_plus = np.max(V, axis=0)   # 假设全是效益型
    A_minus = np.min(V, axis=0)
    # 距离
    D_plus = np.sqrt(np.sum((V - A_plus)**2, axis=1))
    D_minus = np.sqrt(np.sum((V - A_minus)**2, axis=1))
    # 贴近度
    C = D_minus / (D_plus + D_minus)
    return C
```

## 权重确定——熵权法

如果题目没给权重，用数据自身的"信息量"确定：

$$
p_{ij} = \frac{x_{ij}}{\sum_{k=1}^{n} x_{kj}}
$$

$$
e_j = -\frac{1}{\ln n} \sum_{i=1}^{n} p_{ij} \ln p_{ij} \quad (p_{ij}=0 \text{ 时取 } 0)
$$

$$
w_j = \frac{1 - e_j}{\sum_{k=1}^{m} (1 - e_k)}
$$

> 熵越大 → 这个指标在所有方案上差不多 → 区分度差 → 权重应该小。

## 常见陷阱

- 忘记区分**效益型**（越大越好）和**成本型**（越小越好）——正负理想解方向相反
- 指标间量纲差太大必须先归一化
- 熵权法要求所有指标都是正向时才能直接用

## 竞赛论文深度要求

- 建立指标表：指标含义、单位、方向、来源和预处理方式。
- 对成本型、区间型、适中型指标先正向化，再归一化。
- 权重来源必须明确：熵权、AHP、专家、等权或组合权重。
- 给出归一化矩阵摘要、权重表、贴近度和最终排名。
- 做权重扰动或归一化方法敏感性，检查前几名是否稳定。
- 不要把 TOPSIS 排名解释成因果结论；它只是综合评价排序。
