# 模糊综合评价

## 一句话

模糊综合评价 = 把"很好、一般、差"这类模糊的定性评价**量化成数字**。当评价指标不能直接测量、只能"打分"时，它比 AHP 更自然。

## 适用场景

| 适合 | 不适合 |
|------|------|
| 评价指标是定性的——"服务质量好"、"教学水平高" | 所有指标都能直接用数字测——用 TOPSIS |
| 评委打分口径差异大——有人打 80，有人打 60 对同一个东西 | 数据精确——直接算加权平均 |

## 四步走

### 1. 确定因素集和评语集

- 因素集 $U = \{u_1, u_2, ..., u_n\}$ ——评价的 n 个维度
- 评语集 $V = \{v_1, v_2, ..., v_m\}$ ——每个维度可能的等级

> 例：$U$ = {教学态度, 教学内容, 教学方法}，$V$ = {优秀, 良好, 一般, 较差}

### 2. 确定权重（AHP 或专家给定）

$$W = (w_1, w_2, ..., w_n), \quad \sum w_i = 1$$

### 3. 单因素评价——构建模糊关系矩阵

对每个因素 $u_i$，统计它在各评语上的隶属度：

$$R = \begin{bmatrix} r_{11} & r_{12} & ... & r_{1m} \\ r_{21} & r_{22} & ... & r_{2m} \\ \vdots & \vdots & \ddots & \vdots \\ r_{n1} & r_{n2} & ... & r_{nm} \end{bmatrix}$$

$r_{ij}$ = 第 $i$ 个因素被评为第 $j$ 个等级的隶属度——通常是对评委打分的统计。如有 10 个评委，7 人评"优秀"，则 $r_{i1} = 0.7$。

### 4. 模糊综合运算

$$B = W \circ R$$

- 普通加权平均：$B = W \times R$（矩阵乘）
- 主因素突出型：$b_j = \max_i \{\min(w_i, r_{ij})\}$（取大取小——适合极端评价需要突出的场景）

最后按最大隶属度原则判定等级——B 向量里哪个分量最大。

## Python 实现

```python
import numpy as np

def fuzzy_eval(weights, R, method='weighted'):
    """weights: n维权重向量, R: n×m 模糊关系矩阵"""
    if method == 'weighted':
        B = weights @ R  # 加权平均
    elif method == 'max_min':
        B = np.array([np.max(np.minimum(weights, R[:, j])) for j in range(R.shape[1])])
    return B

# 示例
W = np.array([0.3, 0.4, 0.3])  # 三要素权重
R = np.array([[0.5, 0.3, 0.2, 0.0],   # 因素1：50%优秀，30%良好...
              [0.6, 0.2, 0.1, 0.1],   # 因素2
              [0.4, 0.4, 0.2, 0.0]])  # 因素3

B = fuzzy_eval(W, R)
grade = np.argmax(B)  # 最大隶属度对应的等级
```

## 隶属度函数的确定

不是所有指标都有评委打分。连续型指标需要先转成隶属度：

| 指标类型 | 隶属度函数 |
|------|------|
| 效益型（越大越好） | $\mu(x) = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$ |
| 成本型（越小越好） | $\mu(x) = \frac{x_{\max} - x}{x_{\max} - x_{\min}}$ |
| 中间型（越接近某值越好） | $\mu(x) = e^{-k(x - a)^2}$ |

## 常见陷阱

- 最大隶属度原则失效：B 的两个分量接近（0.35 vs 0.33）——不能硬判最高等级
- 评价等级太多（>7）——人无法区分——最好 4–5 个等级
- 隶属度函数选的太随意——最好说清为什么选线性/高斯
