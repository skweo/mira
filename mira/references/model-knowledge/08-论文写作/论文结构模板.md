# 数学建模论文结构模板

## 标准结构

```
摘要（一页以内，最重要）
1. 问题重述
2. 基本假设
3. 符号说明
4. 模型的建立与求解（核心——占 60% 篇幅）
5. 模型检验与灵敏度分析
6. 模型评价与改进
7. 参考文献
```

## 摘要——最重要的一页

**必须包含的东西：**

| 段落 | 内容 | 注意 |
|------|------|------|
| 第一句 | 针对什么问题 | 一句话说清题目 |
| 第二段 | 用了什么方法（每个问题一句话） | "问题一：建立了 XXX 模型……" |
| 第三段 | 主要结果——数字！ | "最优利润为 123.4 万元，误差 < 3%" |
| 第四段 | 模型特点/创新点 | "与传统的 XXX 相比，本模型……" |
| 最后 | 关键词 | 3–5 个 |

> 摘要决定评委要不要继续读。数字比形容词值钱——"精度高"不如"误差 < 2.3%"。

## 基本假设

每条假设必须说**为什么这么假设**——不是列出，是辩护：

```
假设 1：XXX 满足正态分布。
  原因：根据中心极限定理，XXX 由大量独立微小因素叠加而成。

假设 2：忽略 XXX 的影响。
  原因：预计算表明 XXX 对结果的贡献 < 1%，且包含它会将模型从 ODE 变成 PDE。
```

> 不要写"为了简化模型"。写"在可接受的精度损失内，该因素的影响可以忽略"。

## 符号说明

| 符号 | 含义 | 单位 |
|------|------|------|
| $x_i$ | 第 $i$ 个决策变量 | — |
| $c_j$ | 第 $j$ 种资源的单位成本 | 元/吨 |
| $\beta$ | 传播率 | 1/天 |

- 全文符号必须统一——换一个变量名评委要重新理解你的模型
- 首用定义——每个符号第一次出现时必须解释

## 模型的建立与求解

这是论文的主体。每个子问题的写法：

```
1. 问题分析——这段话在讲什么
2. 模型建立——数学公式，逐量解释
3. 模型求解——用什么方法、什么工具求的
4. 结果——数字、图表——放在这里
```

> 先讲"为什么这个模型"——再写公式。直接丢公式不给理由 = 典型扣分点。

## 灵敏度分析

不是"把参数改一下看看结果变没变"——是：

| 分析 | 做什么 |
|------|------|
| 灵敏度 | 每个关键参数 ±10%、±20% → 结果变化多少？哪个参数最敏感？ |
| 稳定性 | 初始条件变了，结论还成立吗？ |
| 误差传播 | 输入数据的测量误差会放大多少倍？ |

## 常见扣分项

- 摘要里没有数字
- 符号表里有的符号正文没出现
- 图没有编号、没有标题、没有坐标轴标签
- "本文模型很优秀"——没有对比就没有优秀。和什么比？比了什么指标？
- 参考文献没有在正文引用——列了但是没标在哪用的
