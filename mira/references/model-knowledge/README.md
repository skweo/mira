# 数学建模知识库

供 Agent 学习的数学建模基础模型与方法库。

## 目录结构

| 文件夹 | 内容 |
|------|------|
| `01-问题分类` | 如何识别题目类型，选择对应方法 |
| `02-优化模型` | 线性规划、整数规划、运输问题、非线性规划、动态规划、多目标优化 |
| `03-评价模型` | AHP、TOPSIS、模糊综合评价、灰色关联、熵权法 |
| `04-预测模型` | 回归、时间序列、灰色预测GM(1,1)、参数辨识与反问题、神经网络、微分方程预测 |
| `05-图论与网络` | 最短路径、网络流、TSP、最小生成树、复杂网络 |
| `06-概率统计` | 假设检验、方差分析、贝叶斯推断、蒙特卡洛模拟 |
| `07-微分方程` | ODE建模、传染病模型、种群竞争、差分方程 |
| `08-论文写作` | 结构模板、符号表、摘要写法、图表规范 |
| `09-交通与服务规划` | 出租车、交通服务、供需容量、价格与政策规划 |
| `10-数值计算与插值` | 插值、空间重采样、缺失值补全、栅格/体素/空间场重建 |
| `11-信号处理与工程实现` | DSP、ASIC/FPGA、定点量化、位宽、吞吐、工程算法仿真与资源权衡、小波分析与小波神经网络 |

## 使用说明

每个模型文件包含：
1. 一句话定义
2. 适用场景
3. 数学模型（公式）
4. 求解步骤
5. 常见陷阱
