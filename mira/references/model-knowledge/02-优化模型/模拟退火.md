# 模拟退火（Simulated Annealing）

## 一句话

模拟退火 = 模仿金属冷却——高温时允许乱跳（探索解空间），温度慢慢降低（越来越保守），最终凝固在最优点附近。比遗传算法更简单，适合单目标连续优化。

## 和遗传算法的对比

| | 遗传算法 | 模拟退火 |
|------|------|------|
| 并行 vs 串行 | 种群——同时维护多个解 | 单解——一个点在山脉上走 |
| 适合 | 组合优化（TSP、0-1 背包） | 连续优化（函数极值、参数标定） |
| 参数 | 种群大小、交叉率、变异率 | 初始温度、降温速度、链长 |
| 调参难度 | 较高（三个参数互相影响） | 较低——初始温度决定了 80% |

## 核心操作：以概率接受更差的解

```
当前解 = x，目标值 = f(x)
随机扰动 → 新解 x'，目标值 f(x')

如果 f(x') < f(x)（新解更好）→ 接受
如果 f(x') > f(x)（新解更差）→ 以概率 P = exp(-Δf / T) 接受
    其中 Δf = f(x') - f(x)（变差了多少）
          T = 当前温度

温度 T 越高 → P 越接近 1 → 几乎都接受（探索）
温度 T 越低 → P 越接近 0 → 几乎不接受差的（收敛）
```

> "以概率接受更差解"是模拟退火跳脱局部最优的唯一机制。没有这一步 = 贪婪下降 = 卡在第一个山谷。

## Python 实现

```python
import numpy as np
import math

def simulated_annealing(f, x0, T0=1000, T_end=0.01, alpha=0.95, L=100):
    """
    f: 目标函数（最小化）
    x0: 初始解
    T0: 初始温度
    alpha: 降温系数（0.8–0.99）
    L: 每个温度下的迭代次数（马尔可夫链长）
    """
    x = x0.copy()
    fx = f(x)
    best_x = x.copy()
    best_fx = fx
    T = T0

    while T > T_end:
        for _ in range(L):
            # 扰动——生成邻域解（连续优化：加正态噪声）
            x_new = x + np.random.normal(0, T/100, size=x.shape)
            fx_new = f(x_new)
            delta = fx_new - fx

            if delta < 0 or np.random.random() < math.exp(-delta / T):
                x = x_new
                fx = fx_new
                if fx < best_fx:
                    best_x = x.copy()
                    best_fx = fx

        T *= alpha  # 降温

    return best_x, best_fx

# 示例：求 f(x,y) = x² + y² + sin(x)cos(y) 的全局最小值
f = lambda p: p[0]**2 + p[1]**2 + math.sin(p[0]) * math.cos(p[1])
best, val = simulated_annealing(f, np.array([10.0, 10.0]))
print(f"最优解: {best}, 目标值: {val}")
```

## 参数调优

| 参数 | 作用 | 建议值 |
|------|------|------|
| **T0** | 初始温度 | 使得初期接受概率 > 80% |
| **alpha** | 降温系数 | 0.9–0.99。越大→越慢→越稳 |
| **L** | 链长 | 50–200。每个温度下探索充分 |
| **T_end** | 终止温度 | 0.01 或 迭代次数到了就停 |

## 常见陷阱

- T0 太低——一开始就不接受差的解 = 没有全局搜索能力
- 降温太快（alpha=0.7）——没给每个温度足够时间去探索
- 扰动步长固定——应该随温度减小：T 大时步长大（跳远），T 小时步长小（精细搜索）
