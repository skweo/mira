# 遗传算法（GA）

## 一句话

遗传算法 = 模仿自然选择来求解优化问题。当目标函数不是线性的、不可导的、多峰的——常规优化方法走不动，GA 随机跳着找。不一定找到最优——但能在可接受的时间内找到**够好的解**。

## 适用场景

| 适合 GA | 不适合 GA |
|------|------|
| 目标函数很复杂、不可导 | 线性规划——单纯形法又准又快 |
| 解空间大、搜索困难（TSP、VRP） | 小规模、精确解可枚举 |
| 多目标优化（NSGA-II） | 约束条件很多很硬 |

## 算法步骤

```
1. 初始化种群——随机生成 N 个个体（每个个体是一个候选解）
2. 评价适应度——每个个体有多"好"（目标函数值）
3. 选择——轮盘赌（适应度越高被选中的概率越大）
4. 交叉——选出的父代两两交换基因片段
5. 变异——以很小的概率随机翻转某段基因
6. 新一代种群形成 → 回到步骤 2
7. 终止——达到迭代次数或适应度收敛
```

## 核心操作

| 操作 | 作用 | 怎么设 |
|------|------|------|
| **种群大小 N** | 同时维持多少个候选解 | 50–200，太小→早熟，太大→慢 |
| **交叉率** | 每对父代产生子代的概率 | 0.6–0.9 |
| **变异率** | 每个基因位翻转的概率 | 0.001–0.01，太大→随机搜索 |
| **精英保留** | 每一代最好的几个直接进入下一代 | 保留 1–3 个——最优解不会退化 |

## 改进型 GA 使用边界

只有在普通 GA 容易早熟、搜索空间很大、局部最优很多，或精确/结构化方法不可行时，才把分层种群、动态交叉变异、混合 SA-GA 等改进写入主模型。若问题能用 LP/MILP、运输问题、网络流、动态规划或枚举小规模精确求解，先用结构化方法。

改进型 GA 不能只写“提高搜索能力”。必须说明：

- 普通 GA 的具体风险：早熟、可行解稀少、局部最优、约束破坏、结果波动大。
- 改进项对应的风险：精英/父代保留防止好解丢失，分层种群维护多样性，动态变异帮助跳出局部区域。
- 新增参数的设置依据：按适应度差距、连续无改进代数、种群相似度、迭代阶段或验证实验调整。
- 额外计算成本是否可接受。

## 分层种群与多样性维护

当种群过快趋同时，不要只保留当前最优个体。可以把种群按适应度分为优秀、中等、较差若干层，再按比例进入下一代：

- 优秀层：保留高质量基因，防止最优解退化。
- 中等层：保持稳定搜索，避免全局搜索完全变成局部贪婪。
- 较差层：保留少量远离当前最优区域的个体，提高跳出局部最优的机会。

论文中需要报告分层比例、保留规则、是否修复不可行个体，以及多样性指标或间接证据。可用证据包括不同种子结果的标准差、连续无改进代数、种群不同解数量、路径/方案差异度或收敛曲线。

## 混合 SA-GA

SA-GA = GA 负责种群级全局搜索，SA 作为局部扰动或接受较差解的算子，帮助跳出局部最优。适用于非线性、多峰、组合优化或约束优化中局部最优风险明显的题。

使用时必须同时记录两套参数：

| 类别 | 必须记录 |
|---|---|
| GA 参数 | 种群规模、代数、选择方式、交叉方式、变异方式、精英/分层保留、随机种子 |
| SA 参数 | 初始温度、降温规则、扰动尺度、链长或每代扰动次数、接受准则、终止温度 |

SA 的“接受较差解”只能用来跳出局部最优，不能用来接受违反硬约束的方案。硬约束仍要通过可行初始化、专用交叉/变异、修复算子或最终约束审计保证。

## Python 实现（求解 TSP）

```python
import numpy as np

def tsp_fitness(route, dist_matrix):
    """路线越短适应度越高"""
    total = sum(dist_matrix[route[i]][route[i+1]] for i in range(len(route)-1))
    total += dist_matrix[route[-1]][route[0]]  # 回到起点
    return 1.0 / total  # 距离的倒数

def crossover(p1, p2):
    """顺序交叉——保留父代路径的片段"""
    n = len(p1)
    i, j = sorted(np.random.choice(n, 2, replace=False))
    child = [-1] * n
    child[i:j] = p1[i:j]
    # 从 p2 中按顺序填不是来自 p1 的城市
    ptr = j
    for city in p2:
        if city not in child:
            child[ptr % n] = city
            ptr += 1
    return child

def mutate(route, rate=0.01):
    """以 rate 概率交换两个城市"""
    route = route.copy()
    for i in range(len(route)):
        if np.random.random() < rate:
            j = np.random.randint(len(route))
            route[i], route[j] = route[j], route[i]
    return route

def genetic_algorithm(dist_matrix, pop_size=100, generations=500):
    n = len(dist_matrix)
    # 初始化
    pop = [list(np.random.permutation(n)) for _ in range(pop_size)]
    best = None
    best_fitness = -1

    for gen in range(generations):
        # 评价
        fitness = [tsp_fitness(r, dist_matrix) for r in pop]
        if max(fitness) > best_fitness:
            best_fitness = max(fitness)
            best = pop[np.argmax(fitness)].copy()

        # 选择（轮盘赌） + 交叉 + 变异
        probs = np.array(fitness) / sum(fitness)
        new_pop = []
        for _ in range(pop_size // 2):
            p1, p2 = pop[np.random.choice(n, 2, p=probs, replace=False)]
            c1 = crossover(p1, p2)
            c2 = crossover(p2, p1)
            new_pop.extend([mutate(c1), mutate(c2)])
        pop = new_pop[:pop_size]

    return best, 1.0/best_fitness
```

## 常见陷阱

- 编码方式选错——TSP 用排列编码，0-1 背包用二进制。编码决定了交叉和变异怎么定义
- 早熟——种群全是同一个解。解法：加大变异率、增大种群
- 适值函数设计——约束要用惩罚项揉进适应度里（违反约束→扣分）
- 把改进算子当装饰——分层种群、动态变异、SA 混合都必须对应明确风险和对照实验。
- 只汇报最好一次——随机启发式至少报告多种子 best/mean/std 和可行率。
- 混合算法无消融——使用 SA-GA 时，要比较普通 GA、SA 或局部搜索、SA-GA，说明新增算子是否真的带来收益。

## 竞赛论文深度要求

- 先定义染色体编码，并证明交叉/变异后仍可解释为可行或可修复的解。
- 写清适应度函数和原目标函数的关系；惩罚项不能只写“很大”。
- 对排列路径类问题，使用顺序交叉、部分映射交叉或专用算子，避免产生重复/缺失节点。
- 对约束很硬的问题，优先用可行初始化、修复算子和约束审计，而不是只靠惩罚。
- 记录种群规模、代数、选择方式、交叉率、变异率、精英保留、随机种子。
- 若使用分层种群、动态交叉/变异或混合 SA-GA，记录分层比例、触发条件、温度/扰动参数和新增算子的作用边界。
- 给出基线和多次运行统计；如果结果波动大，要解释原因或换更稳的方法。
- 改进型 GA 至少给普通 GA 或更简单启发式基线；混合 SA-GA 需要消融对照。
- 给出收敛曲线或参数敏感性表，但不要把曲线当作唯一证据。
- 论文中必须给最终个体解码后的实际方案表，不能只给适应度曲线。
- 没有精确比较、下界或证明时，不要称 GA 结果为全局最优。

## 推荐输出文件

| 文件 | 作用 |
|---|---|
| `ga_parameters.json` | 固定种群、代数、算子、随机种子和 SA 参数 |
| `ga_runs.csv` | 多种子 best/mean/std、可行率、收敛代数 |
| `ga_convergence.csv` | 每代最优值、平均值、可行个体数或多样性指标 |
| `ga_solution_decoded.csv` | 最终个体解码后的路线/分配/排程/参数表 |
| `ga_constraint_audit.csv` | 硬约束逐项审计和目标值复算 |
