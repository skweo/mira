# Model Card: 目标规划与多目标优化

## Use When

- 题目同时要求多个冲突目标，如成本最低、时间最短、收益最大、风险最小。
- 每个目标都有可计算表达式，且需要给出折中方案。
- 目标之间量纲不同，需要设置优先级、权重、目标值或满意度。

## Avoid When

- 题目只有一个明确目标。
- 各目标不能量化或没有数据支撑。
- 权重/优先级完全无法解释，也不能做敏感性分析。
- 一个目标是硬约束，应写入约束而不是放进加权目标。
- 问题天然是分阶段依赖的，例如先预测需求、再分配资源、再安排车辆或场地；此时优先使用阶段化/词典序/候选方案比较，不要一开始就任意加权成一个目标。

## Typical Contest Tasks

- 多目标资源配置。
- 生产/运输/调度折中。
- 方案选择与政策优化。
- 成本-效率-公平-风险综合决策。

## Required Inputs

| Input | Meaning | Unit | Required? | Notes |
|---|---|---|---:|---|
| Decision variables | 决策变量 | mixed | yes | 与每个目标和约束关联 |
| Objective functions | 多个目标函数 | mixed | yes | 方向和单位要明确 |
| Hard constraints | 资源、容量、逻辑、边界 | mixed | yes | 不应被软目标替代 |
| Goal/aspiration values | 各目标理想值或期望值 | mixed | if using goal programming | 可先单目标求解 |
| Weights or priority | 目标权重/优先级 | none | yes | 来源、题意或敏感性 |

## Outputs

| Output | Meaning | Paper use |
|---|---|---|
| Single-objective optima | 每个目标单独最优值 | 解释冲突和理想点 |
| Compromise solution | 折中方案 | 最终推荐 |
| Objective table | 各目标取值和偏差 | 结果分析 |
| Sensitivity table | 权重/优先级变化结果 | 稳健性 |

## Variables and Parameters

| Symbol | Type | Meaning | Unit | Source or estimation |
|---|---|---|---|---|
| `x` | variable | 决策变量向量 | mixed | 当前问题 |
| `f_k(x)` | function | 第 `k` 个目标 | mixed | 模型定义 |
| `g_k` | parameter | 第 `k` 个目标期望值 | mixed | 单目标求解或题意 |
| `w_k` | parameter | 第 `k` 个目标权重 | none | 题意/专家/敏感性 |
| `d_k^+,d_k^-` | variable | 正/负偏差变量 | mixed | 目标规划 |

## Core Formulation

常见目标规划形式：

```text
minimize sum_k w_k (alpha_k d_k^+ + beta_k d_k^-)
subject to f_k(x) + d_k^- - d_k^+ = g_k
           hard_constraints(x)
           d_k^+, d_k^- >= 0
```

若使用加权和：

```text
minimize sum_k w_k normalized_f_k(x)
subject to hard_constraints(x)
```

先单目标求各 `g_k` 或理想点，再解释为什么最终折中方案偏离这些目标。

## Solver or Implementation Route

- Preferred language: Python (`scipy.optimize`, `pulp`, `ortools`) or MATLAB.
- Data preprocessing: normalize objectives with different units.
- Baseline: each objective's single-objective optimum and a simple equal-weight scheme.
- Complexity: depends on whether `f_k` and constraints are linear, integer, nonlinear, or mixed.

## Validation

- Feasibility check: all hard constraints.
- Sensitivity check: weights, priority levels, target values.
- Baseline comparison: compare compromise against single-objective optima.
- Tradeoff check: explain which objective is sacrificed and by how much.

## Paper Writing Notes

- 先解释目标冲突，再写数学形式。
- 权重、优先级或期望值不是装饰，要有来源或敏感性。
- 最终方案要写清相对各单目标理想值的偏差。
- 如果第一阶段有多个同等最优方案，保留候选集，用第二阶段成本、距离、便利性或可行性再筛选。

## Common Pitfalls

- 把硬约束当成软目标，导致不可行方案被推荐。
- 未归一化不同量纲目标。
- 权重只给一组且无敏感性。
- 只说“综合最优”，不解释折中含义。
- 把参与者/客户支付的成本误写成组织者的直接成本，导致目标函数错位。
