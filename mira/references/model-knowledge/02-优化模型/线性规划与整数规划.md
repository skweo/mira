# 线性规划与整数规划

## 一句话

**线性规划** = 目标函数和约束条件都是线性的，求最大值或最小值。**整数规划** = 决策变量必须是整数（人数、辆数、机器台数）。

## 线性规划标准形式

$$
\begin{aligned}
\min \quad & \mathbf{c}^T \mathbf{x} \\
\text{s.t.} \quad & \mathbf{A}\mathbf{x} \leq \mathbf{b} \\
& \mathbf{x} \geq 0
\end{aligned}
$$

| 符号 | 含义 |
|------|------|
| $\mathbf{x}$ | 决策变量向量（$n$ 维） |
| $\mathbf{c}$ | 目标函数系数 |
| $\mathbf{A}$ | 约束矩阵（$m \times n$） |
| $\mathbf{b}$ | 约束右端向量（$m$ 维） |

## 整数规划的分类

| 类型 | 条件 | 例子 |
|------|------|------|
| 纯整数规划 | 所有变量必须是整数 | 生产计划（不能生产 3.5 辆车） |
| 0-1 规划 | 变量只能取 0 或 1 | 选址问题（建或不建）、指派问题 |
| 混合整数规划 | 部分变量整数，部分连续 | 生产数量（整数）+ 原材料用量（连续） |

## 求解方法

| 方法 | 适用 | 原理 |
|------|------|------|
| 单纯形法 | 纯线性规划 | 在顶点间移动找最优 |
| 分支定界 | 整数规划 | 把整数约束拆成"≤ a"和"≥ a+1"两棵树 |
| 割平面法 | 整数规划 | 不断加线性约束切掉非整数解 |

## Python 实现

```python
from scipy.optimize import linprog

# min c^T x, s.t. A_ub @ x <= b_ub, A_eq @ x == b_eq, bounds
c = [-1, -2]        # 目标系数（求最大取相反数）
A_ub = [[1, 1], [2, 1]]
b_ub = [6, 8]
bounds = [(0, None), (0, None)]

res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
print(f'最优解: x={res.x}, 最优值: {-res.fun}')
```

对于整数规划，使用 `pulp` 或 `ortools`：

```python
from pulp import LpMaximize, LpProblem, LpVariable

prob = LpProblem("demo", LpMaximize)
x = LpVariable("x", lowBound=0, cat="Integer")
y = LpVariable("y", lowBound=0, cat="Integer")
prob += 3*x + 2*y              # 目标
prob += 2*x + y <= 8            # 约束1
prob += x + 2*y <= 6            # 约束2
prob.solve()
```

## 敏感性分析

求出最优解后，必须回答：
- 某个约束右边加 1，最优值变多少？（影子价格）
- 目标系数在什么范围内，最优解不变？

## 常见陷阱

- 忘记写非负约束
- 整数规划不能直接解线性松弛后四舍五入——可能不是最优甚至不可行
- 变量和约束太多（>1000个变量）时线性规划也很慢

## 竞赛论文深度要求

- 变量、目标系数、约束矩阵、右端项和上下界必须与实际含义对应。
- 对 0-1 指派、选址、路径选择、车辆使用等变量，要明确二进制含义。
- 如果使用整数规划/MILP，记录求解器、时间限制、gap、节点数或终止原因。
- 不能把 LP 松弛结果四舍五入后当作整数规划最优解；必须重新审计可行性。
- 给出约束审计表：等式约束、容量、覆盖、资源、非负和整数性。
- 对关键资源约束，做右端项或成本系数敏感性分析。
- 只有 solver gap 或理论证明支持时，才写全局最优。
