# Model Card: 小波分析与小波神经网络

## Use When

- 输入是非平稳信号、图像、传感器序列、金融/交通/工程时序，且局部突变、噪声、周期变化或多尺度结构会影响结论。
- 任务需要去噪、压缩、突变点识别、频带能量特征、时频特征，或将多尺度特征送入预测/分类模型。
- 有足够采样点，且能验证小波处理前后的误差、稳定性或后续模型提升。

## Avoid When

- 数据点很少，采样间隔不清楚，或信号不是按时间/空间顺序采样。
- 只需要简单平滑、移动平均、回归或常规滤波即可解释。
- 不能说明小波基、分解层数、阈值/重构规则和边界处理。
- 小波神经网络没有训练/验证/测试划分、基线或过拟合检查。

## Typical Contest Tasks

- 信号去噪、图像去噪、趋势/突变识别、时频特征提取、交通流量短时预测、传感器异常检测、工程状态识别、预测模型的特征工程。

## Required Inputs

| Input | Meaning | Unit | Required? | Notes |

| Signal or image | 原始序列、二维图像或多维观测 | problem-specific | yes | 记录采样间隔、单位、缺失值 |
| Sampling rule | 时间/空间采样规则 | s/m/frame/etc. | yes | 不规则采样需先重采样或说明处理 |

| Baseline | 对照方法 | none | yes | 移动平均、低通滤波、原始特征、普通 BP/回归等 |

## Outputs

| Output | Meaning | Paper use |
|---|---|---|
| Denoised or reconstructed signal | 去噪/重构结果 | 与原始信号对比、后续建模输入 |

## Variables and Parameters

| Symbol | Type | Meaning | Unit | Source or estimation |
|---|---|---|---|---|
| `x_t` | observed data | 原始信号或序列 | problem-specific | 附件或传感器数据 |
| `psi` | parameter | 小波基函数 | none | 按任务和验证选择 |
| `L` | parameter | 分解层数 | count | 采样频率、信号长度或验证 |
| `lambda` | parameter | 阈值 | signal unit | 噪声估计、交叉验证或经验规则 |
| `c_{l,k}` | intermediate | 第 `l` 层第 `k` 个小波系数 | signal unit | 小波变换 |
| `z` | derived feature | 小波特征向量 | mixed | 频带统计或系数统计 |
| `y_hat` | output | 预测/分类/重构输出 | target unit | 后续模型 |

## Core Formulation

常规小波处理链：

```text
原始数据 x -> 预处理/补缺/重采样 -> 小波分解 -> 系数处理
             -> 重构信号或提取多尺度特征 -> 验证 -> 后续模型
```

小波神经网络链：

```text
z = wavelet_features(x) 或 h_j = psi((w_j x - b_j) / a_j)
y_hat = NN_wavelet(z; theta)
theta* = argmin loss(y_hat, y)
```

必须说明小波层负责什么，神经网络层负责什么。不要把“小波神经网络”写成一个黑箱名词。

## Solver or Implementation Route

- Preferred language: Python (`PyWavelets`, `numpy`, `scipy`, `sklearn`) or MATLAB Wavelet Toolbox when available.
- MATLAB examples from `Math_Model` are implementation hints only；改写时必须保存参数、输出表和图形数据。
- Data preprocessing: sort by time/space, handle missing values, normalize when feeding a neural network, record sampling interval.
- Baseline: raw signal model, moving average, low-pass filter, ARIMA/GM(1,1), regression, ordinary BP network or simple classifier.
- For WNN: record architecture, wavelet activation/basis, hidden nodes, learning rate, stopping rule, seed, split plan.

## Validation

- Denoising/reconstruction: compare SNR, RMSE/MAE, residual variance, smoothness and signal-feature preservation.
- Feature extraction: compare downstream model performance with and without wavelet features.
- Boundary sensitivity: test decomposition level, wavelet basis, threshold rule, and boundary extension when they materially affect results.
- WNN: holdout/cross-validation, baseline comparison, train-vs-validation loss, seed stability or repeated runs.
- Never report only a pleasing reconstructed curve; save numeric metrics and the data behind every figure.

## Paper Writing Notes

- 中文竞赛论文中先说明“为什么需要多尺度/时频处理”，再写小波基和分解层数。
- 小波处理通常是数据处理或特征工程，不要把它包装成完整主模型，除非题目核心就是信号处理。
- 小波神经网络应按神经网络模型写清输入、结构、损失、训练设置和验证，不要只贴误差曲线。
- 图应支持具体结论：噪声降低、突变点定位、关键频带贡献、预测误差下降。

## Common Pitfalls

- 文件名叫小波分析，但实际只是小波神经网络演示，误当通用小波模板。
- 小波基和层数凭感觉选择，没有敏感性或误差比较。
- 边界延拓和采样间隔不说明，导致重构边缘失真。
- 小样本用复杂 WNN，训练误差下降但泛化无证据。
- 只给原始/重构曲线，不给残差、误差指标或后续模型提升。
