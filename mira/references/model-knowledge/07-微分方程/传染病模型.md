# 传染病模型（SIR 与变种）

## 一句话

SIR = 把人群分成**易感者（S）、感染者（I）、移出者（R）**三个仓室，用微分方程组描述疫情传播。是微分方程建模最经典的案例——掌握了这套仓室模型思路，几乎所有"传播/扩散"类题目都能用。

## SIR 模型

$$
\begin{aligned}
\frac{dS}{dt} &= -\beta \frac{SI}{N} \\
\frac{dI}{dt} &= \beta \frac{SI}{N} - \gamma I \\
\frac{dR}{dt} &= \gamma I
\end{aligned}
$$

| 参数 | 含义 |
|------|------|
| $\beta$ | 传播率——一个感染者每天传染多少人 |
| $\gamma$ | 移出率——$1/\gamma$ = 平均感染期（天） |
| $R_0 = \beta / \gamma$ | 基本再生数——一个感染者在全易感人群中平均传染多少人 |
| $N = S + I + R$ | 总人口（不变） |

> $R_0 > 1$ → 疫情蔓延。$R_0 < 1$ → 疫情消退。这是公共卫生最核心的数字。

## 常见变种

| 模型 | 多了什么仓室 | 适合 |
|------|------|------|
| **SIS** | 无 R——痊愈后直接回 S | 流感、普通感冒（不会终身免疫） |
| **SEIR** | +E（Exposed，潜伏期） | 新冠、SARS（有潜伏期，潜伏期内不传染或不完全传染） |
| **SEIQR** | +Q（隔离）+E（潜伏） | 有隔离政策的新冠模型 |
| **SIRD** | +D（死亡）从 I 分流 | 需要考虑死亡率的场景 |

## 求解 SEIR 模型

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

def seir(y, t, beta, sigma, gamma, N):
    S, E, I, R = y
    dS = -beta * S * I / N
    dE = beta * S * I / N - sigma * E
    dI = sigma * E - gamma * I
    dR = gamma * I
    return [dS, dE, dI, dR]

# 参数
N = 1e7
beta = 0.3         # 传播率
sigma = 1/5.2      # 潜伏期 5.2 天
gamma = 1/14       # 感染期 14 天

y0 = [N-1, 1, 0, 0]  # 初始：1 个感染者，其他全易感
t = np.linspace(0, 200, 1000)

result = odeint(seir, y0, t, args=(beta, sigma, gamma, N))
S, E, I, R = result.T

plt.plot(t, S, label='S(易感)')
plt.plot(t, E, label='E(潜伏)')
plt.plot(t, I, label='I(感染)')
plt.plot(t, R, label='R(移除)')
plt.legend()
plt.show()
```

## 扩展到非传染病场景

这套仓室模型的思路可以用于任何"状态转移"：

| 场景 | S→? | I→? | R→? |
|------|------|------|------|
| 谣言传播 | 不知道的人 | 传播谣言的人 | 不信的人 |
| 创新扩散 | 没买的人 | 买了的人 | 弃用的人 |
| 信息传播 | 未接收 | 转发中 | 已阅不再转发 |

> 建模的本质：识别系统中的"状态"和"转换规则"，写出微分/差分方程组。

## 常见陷阱

- $S(t) + I(t) + R(t)$ 加起来不等于 N——检查守恒
- 参数没有现实依据——$\beta$ 和 $\gamma$ 需要有数据支撑或文献引用
- 人口变动（出生、死亡、流动）——如果时间跨度长，需要考虑
