# Model Card: 三维插值与空间重采样

## Use When

- 题目给出离散点、网格、体素、传感器点、地图栅格或时空场，需要估计未知位置的值。
- 需要补全缺失值、把数据重采样到统一网格、生成等值线/曲面，或从三维数据中取任意截面。
- 下游优化、评价或仿真依赖一个连续空间场或更细分辨率的数据表示。

## Avoid When

- 需要预测未来或因果关系，而不是估计样本之间的空间/时间位置。
- 数据极稀疏且没有可验证的平滑性、空间相关性或外部约束。
- 目标点在样本凸包外很远，主要问题已经变成外推。
- 数据存在强不连续边界，但无法检测边界，也不能接受平滑造成的偏差。

## Typical Contest Tasks

- 数值计算、空间重建、缺失值补全、图像/栅格处理、传感器场重建、地理空间分析、仿真预处理。

## Variables and Parameters

| Symbol | Type | Meaning | Unit | Source or estimation |
|---|---|---|---|---|
| `V_{i,j,k}` | observed value | 网格点观测值 | problem-specific | 原始数据或预处理结果 |
| `(x_i,y_j,z_k)` | coordinate | 网格点物理坐标 | coordinate unit | 由坐标表或采样间隔得到 |
| `dx,dy,dz` | parameter | 三个方向采样间隔 | coordinate unit | 附件说明或数据推断 |
| `p=(x,y,z)` | target | 待估计位置 | coordinate unit | 题目目标或重采样网格 |
| `K` | method | 插值核/邻域规则 | none | 模型选择 |
| `tau` | parameter | 边界/不连续检测阈值 | value unit | 数据驱动或敏感性分析 |

## Core Formulation

规则网格上的三线性插值可作为基线。设目标点 `p=(x,y,z)` 位于网格单元 `(i,j,k)` 与 `(i+1,j+1,k+1)` 之间，定义

```text
u = (x - x_i) / dx
v = (y - y_j) / dy
w = (z - z_k) / dz
```

则

```text
V_hat(p) = sum_{a,b,c in {0,1}} V_{i+a,j+b,k+c}
           * weight_a(u) * weight_b(v) * weight_c(w)
```

其中 `weight_0(t)=1-t`，`weight_1(t)=t`。

三次/三维三次插值使用每个方向相邻的 4 个点，并沿各轴依次做一维三次插值。若场具有明显不连续边界，可使用局部检测规则：

```text
if local_gradient_or_jump > tau:
    use nearest-neighbor or edge-preserving estimate
else:
    use linear/cubic/polynomial/spline estimate
```

不规则散点数据优先考虑 RBF、克里金、局部回归或先重采样到规则网格；不要直接套用规则网格公式。

## Solver or Implementation Route

- Preferred language: Python for reproducible data IO, SciPy interpolation, NumPy grids, Matplotlib plots; MATLAB is suitable when已有 `.m` 插值/图像处理代码可信且可审计。
- Recommended packages: `numpy`, `scipy.interpolate`, `pandas`, `matplotlib`; GIS 数据可考虑 `geopandas`/`rasterio` only when already available.
- Data preprocessing: audit units, duplicate coordinates, missing values, grid regularity, axis order, and anisotropic spacing.
- Baseline: nearest neighbor and linear/trilinear interpolation.
- Complexity or runtime notes: report grid size, target-point count, method parameters, and runtime when interpolation is large or repeated.

## Validation

- Feasibility check: target points lie in the valid domain or are flagged as extrapolation.
- Sensitivity check: perturb sampling interval, slice orientation, kernel parameter, or discontinuity threshold.
- Baseline comparison: compare with nearest neighbor, linear/trilinear, and the selected higher-order method when possible.
- Error or uncertainty check: use holdout points, synthetic ground truth, residual/error maps, MAE/RMSE, and local error inspection.

## Paper Writing Notes

- 用中文先说明“已知数据表示”和“要估计的位置”，再写插值公式。
- 把插值说成“估计/重建/补全”，不要写成真实测量值。
- 如果插值结果进入优化或评价，明确写出“插值输出 -> 下游模型输入”的交接。
- 图表按证据需要选择：空间场可用热力图/等值线/截面图，曲线数据用拟合曲线和残差图，方法选择用比较表。

## Common Pitfalls

- 坐标单位和网格索引混用。
- 忽略 `dx,dy,dz` 不相等导致图形或距离失真。
- 在边界外大量外推却仍称为插值。
- 对有不连续边界的数据使用平滑插值后不做误差解释。
- 只展示漂亮重建图，没有留出误差、基线比较或残差分析。
- 把每篇论文都固定加热力图/流程图；插值图表必须服务于当前证据链。
