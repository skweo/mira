# Model Card: 参数辨识与反问题

## Use When

- 题目给出物理、几何、工程、系统或机制模型，并要求根据检测数据反推未知参数。
- 题目要求标定、校准、变位识别、故障参数识别、模型参数估计或反演。
- 观测数据是模型输出、输出变化量、残差、检测序列或校准数据。

## Avoid When

- 没有明确的正向模型，也无法建立观测量与参数之间的关系。
- 数据字段含义不清，无法判断拟合目标是什么。
- 参数不可辨识，多个参数组合产生几乎相同输出，且无法做灵敏度或约束。
- 只需要普通预测，不需要解释或反推机制参数。

## Typical Contest Tasks

- 几何/物理参数反演。
- 标定曲线和校准表生成。
- 工程系统参数识别。
- 非线性最小二乘拟合。
- 检测数据驱动的模型修正。

## Required Inputs

| Input | Meaning | Unit | Required? | Notes |
|---|---|---|---:|---|
| Forward model | 正向模型 `y = F(x, theta)` | mixed | yes | 必须说明输入、输出和参数 |
| Observations | 检测或实验数据 | mixed | yes | 区分实测、显示、累计、变化量 |
| Unknown parameters | 待识别参数 `theta` | mixed | yes | 给出物理范围和单位 |
| Fitting target | 用于拟合的观测量 | mixed | yes | 必须与模型输出语义一致 |
| Loss function | 残差准则 | objective unit | yes | 加权/未加权、绝对/相对残差 |
| Validation data | 独立检验段或留出数据 | mixed | if available | 不应只用拟合段评价 |

## Outputs

| Output | Meaning | Paper use |
|---|---|---|
| Parameter table | 参数估计值、单位、范围 | 主结果 |
| Residual table | 拟合残差 | 模型诊断 |
| Validation metrics | 检验集误差或对比 | 可靠性说明 |

## Variables and Parameters

| Symbol | Type | Meaning | Unit | Source or estimation |
|---|---|---|---|---|
| `x_i` | input | 第 `i` 个观测输入 | mixed | 数据表 |
| `y_i` | observation | 第 `i` 个观测目标 | mixed | 数据表，需说明语义 |
| `theta` | parameter | 待辨识参数向量 | mixed | 估计 |
| `F(x_i, theta)` | function | 正向模型预测 | same as `y_i` | 模型 |
| `r_i(theta)` | residual | 观测与模型的差异 | same as `y_i` | 计算 |

## Core Formulation

一般形式：

```text
theta_hat = argmin_theta sum_i w_i r_i(theta)^2
subject to theta_min <= theta <= theta_max
           mechanism_constraints(theta)
```

其中残差必须按题意定义。例如观测的是变化量时，应比较：

```text
r_i(theta) = observed_change_i - (F(x_i_after, theta) - F(x_i_before, theta))
```

而不是把显示值、旧标定值或派生值直接当作真实目标。

## Solver or Implementation Route

- Preferred language: Python (`scipy.optimize.least_squares`, `curve_fit`, `differential_evolution`) or MATLAB (`lsqcurvefit`, `fmincon`).
- Baseline: zero-parameter/no-change model, known-parameter case, simple curve fit, or grid-search sanity check.
- Data preprocessing: field semantics, units, cumulative-to-increment conversion, abnormal values, train/validation split.
- Parameter bounds: use physical, geometric, engineering, or contest-stated ranges.
- Save: fitted parameters, residuals, predicted-vs-observed table, validation metrics, run settings, and final requested table.

## Validation

- Semantics check: fitted target matches the model output or model output change.
- Residual check: residual size, trend, outliers, and systematic bias.
- Independent validation: fit on one segment and verify on another when data permit.
- Sensitivity check: perturb each key parameter and observe loss/result changes.
- Identifiability check: report if different parameter sets produce near-equivalent fits.
- Limiting-case check: verify the model when parameters take known simple values.

## Paper Writing Notes

- 先写正向模型，再写反问题辨识；不要直接从数据跳到参数值。
- 明确说明拟合准则和数据字段含义。
- 参数表附近应放残差、验证或灵敏度证据。
- 如果题目要求校准表、修正表或间隔表，必须在正文给出关键内容，完整表可保存为独立结果文件，并在摘要中说明关键结论。
- 只在有足够证据时说参数可靠；否则写成当前模型下的估计值。

## Common Pitfalls

- 用错误字段拟合，例如把显示值、旧模型计算值或累计量当作真实目标。
- 只写“最小二乘求得参数”，不写残差定义、参数范围和数据段。
- 拟合和检验使用同一批数据，却声称模型可靠。
- 参数高度相关但不做灵敏度或可辨识性分析。
- 给出参数但漏掉题目要求的标定表或最终交付物。
- 用 Monte Carlo 近似几何积分却没有收敛或误差说明。
