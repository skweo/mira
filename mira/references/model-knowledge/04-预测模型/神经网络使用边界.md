# Model Card: 神经网络使用边界

## Use When

- 数据量足够，特征和目标有非线性关系。
- 任务是预测、分类、函数逼近或复杂模式识别。
- 可以设置训练/验证/测试划分，并与简单模型比较。
- 已明确学习范式：监督学习、无监督学习或强化学习，并能给出对应的评价标准。
- 分类任务需要非线性分界，或已经通过线性模型基线说明单纯线性边界不足。

## Avoid When

- 样本很少或只有演示数据级别。
- 变量含义和特征工程无法解释。
- 题目需要清晰机制推导，而神经网络无法提供足够解释。
- 没有验证集、误差指标或基线。
- 小波神经网络、深度网络或混合智能算法只是因为代码示例存在而被选用，当前题目没有足够样本和对照验证。
- 单层感知机用于线性不可分数据，或没有检查线性可分性就把感知机作为分类主模型。

## Typical Contest Tasks

- 非线性预测。
- 分类识别。
- 高维特征拟合。
- 与传统预测模型的对比方案。
- 系统辨识、故障诊断、信号特征提取或控制器近似，但必须有独立验证。

## Core Formulation

神经网络在竞赛论文里通常作为函数近似器：

```text
y_hat = NN(x; theta)
theta* = argmin loss(y_hat, y) + regularization
```

必须说明输入、输出、损失函数和训练方式。

人工神经元的最小解释结构：

```text
s = sum(w_i * x_i) + b
y = activation(s)
```

在论文中把它解释为“输入特征经过加权求和和非线性映射得到预测/分类输出”即可，不需要展开生物神经元背景。

先判定学习范式：

| 学习方式 | 必须说明 | 常见竞赛用途 |
|---|---|---|
| 监督学习 | 标签/目标值、损失函数、训练/验证/测试 | 预测、分类、函数逼近 |
| 无监督学习 | 内部评价标准、聚类/表示结果、稳定性 | 聚类、降维、异常模式发现 |
| 强化学习 | 状态、动作、奖励、策略更新、仿真环境 | 序贯决策；竞赛中慎用 |

感知机和 BP 网络的最小边界：

| 网络类型 | 可用场景 | 必须补充 | 不可这样用 |
|---|---|---|---|
| 单层感知机 | 近似线性可分的二分类 | 线性可分性说明、分类超平面、线性/逻辑回归/SVM 基线 | 用于 XOR 或明显非线性分界 |
| 多层感知机/BP 网络 | 非线性拟合、预测、分类 | 输入输出样本、层数节点、激活函数、损失、初始化、训练算法、停止规则 | 只给训练拟合曲线，不给验证误差和基线 |

BP 网络按“正向传播计算输出，反向传播根据误差调整权值和阈值”解释即可。论文重点放在当前题目的样本、特征、损失函数、验证结果和稳定性，而不是展开课堂级链式求导。

BP 训练优化器是可审计设置，不是模型有效性的证明。若使用最速下降、线搜索、共轭梯度、牛顿/高斯-牛顿或 Levenberg-Marquardt 训练，应记录训练器名称、学习率或线搜索/阻尼参数、迭代上限、停止规则、收敛曲线和失败重试。训练器只能说明权值如何更新；是否可作为主模型仍取决于验证集/测试集误差、基线比较和过拟合检查。

## Solver or Implementation Route

- Preferred language: Python (`scikit-learn`, `pytorch`, `tensorflow`) or MATLAB toolbox if already available.
- Data preprocessing: scaling, missing values, categorical encoding.
- Baseline: linear regression, ARIMA/GM(1,1), decision tree, or simple classifier.
- Runtime notes: record seed, split, initialization rule, training algorithm, epochs, early stopping, and hardware/toolbox.

## Validation

- Holdout or cross-validation.
- Baseline comparison.
- Overfitting check: train vs validation error.
- Sensitivity check: feature subset, architecture size, or seed.
- BP/MLP requires repeated initialization or repeated random seeds when the result changes materially.
- Perceptron classification requires a linear-separability check or comparison with a simple linear classifier.
- 分类任务给混淆矩阵、Accuracy/F1/Recall 等；回归/预测给 MAE/RMSE/MAPE 等。
- 无监督任务给轮廓系数、类内/类间距离、重构误差、稳定性或业务合理性检查。
- 强化学习任务给仿真环境、奖励曲线、策略稳定性、基线策略和安全/约束审计。

## Paper Writing Notes

- 只有当神经网络确实提高验证性能时才放在主模型中。
- 样本少时，神经网络最多作为对比或备选，不宜作为唯一主模型。
- 不写“智能算法更先进”这类空话；用误差和稳定性说话。
- 小波神经网络应先说明小波特征或小波激活函数的作用，再按神经网络要求报告结构、训练设置、基线和验证误差。
- 论文中少写生物神经网络类比，多写当前题目的输入、输出、特征、损失、验证和适用边界。
- 如果只需要线性分类，优先用可解释的线性模型；BP 网络应在非线性关系和验证提升明确时才升级为主模型。

## Common Pitfalls

- 用同一批数据训练和测试。
- 没有标准化输入。
- 只给拟合曲线，不给误差指标。
- 小样本高复杂网络导致过拟合。
- 把 MATLAB 演示代码中的学习率、节点数、误差阈值和最大迭代次数直接套到竞赛数据。
- 没有说明监督/无监督/强化学习范式，导致模型目标和验证指标混乱。
- 把神经网络用于硬约束优化，却没有可行性审计或约束修复。
- 把同一组数据同时作为训练集和测试集，例如直接复制正弦拟合 demo 的 `train` 后再在原样本上 `sim`。
- 因为 BP 理论上能逼近非线性函数，就跳过样本量、泛化误差、局部最小和结构选择风险。
- 把 LM、共轭梯度或线搜索当成泛化性能证明；它们只说明训练优化路线，不能替代验证集误差。
