# Model Card: 回归建模与诊断

## Use When

- 需要解释或预测连续变量，且有候选影响因素。
- 样本量足以支持变量数量。
- 变量关系可近似为线性、多项式、非线性可参数化或可变换形式。

## Avoid When

- 样本极少且变量很多。
- 变量含义不清或存在严重时间泄漏。
- 目标是分类、排序或机制仿真而非连续预测/解释。
- 只想得到高拟合度但无法解释或验证。

## Typical Contest Tasks

- 指标影响因素分析。
- 连续变量预测。
- 参数拟合。
- 多因素关系解释。

## Required Inputs

| Input | Meaning | Unit | Required? | Notes |
|---|---|---|---:|---|
| Target `y` | 被解释/预测变量 | problem-specific | yes | 单位明确 |
| Predictors `X` | 自变量矩阵 | mixed | yes | 说明来源和单位 |
| Sample index | 样本/时间/地区编号 | mixed | yes | 防止泄漏 |
| Train/test split | 验证划分 | none | if predictive | 时间序列要按时间划分 |

## Outputs

| Output | Meaning | Paper use |
|---|---|---|
| Coefficients | 回归系数 | 模型解释 |
| Confidence intervals | 系数置信区间 | 显著性和不确定性 |
| Residual table/plot | 残差 | 诊断 |
| Error metrics | MAE/RMSE/R2等 | 验证 |

## Core Formulation

```text
y = beta_0 + beta_1 x_1 + ... + beta_p x_p + epsilon
```

多项式、非线性或逐步回归必须说明变量选择和过拟合风险。

## Solver or Implementation Route

- Preferred language: Python (`statsmodels`, `scikit-learn`) or MATLAB.
- Data preprocessing: missing values, outliers, scaling, transformations.
- Baseline: mean predictor, simple trend, or single-variable model.
- Complexity: sample size should substantially exceed variable count.

## Validation

- Residual check: residual distribution, outliers, heteroscedasticity where relevant.
- Baseline comparison: against simple model.
- Holdout/CV: use when the goal is prediction.
- Sensitivity check: remove outliers or key variables.

## Paper Writing Notes

- 先说明自变量选择理由，再给模型。
- 不把相关性写成因果。
- 若用于预测，重点写误差；若用于解释，重点写系数含义和显著性。

## Common Pitfalls

- 样本少、变量多仍做高阶多项式。
- 只报告 `R^2`，不看残差和泛化误差。
- 时间序列随机划分训练测试，造成未来信息泄漏。
