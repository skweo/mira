# 灰色预测 GM(1,1)

## 一句话

GM(1,1) = **数据少（4–10 个点）时最好用的预测方法**。把小样本、贫信息的数据变成指数规律来预测。数据多了反而不好——那是时间序列和回归的地盘。

## 适用场景

| 条件 | 适合 GM(1,1) |
|------|------|
| 数据点数量 | 4–10 个 |
| 数据特点 | 单调递增或递减（如 GDP、产量、人口） |
| 不适合 | 数据波动大、有周期性、数据多（>20 个） |

## 算法步骤

### 1. 原始序列 + 一次累加

原始序列：$X^{(0)} = \{x^{(0)}(1), x^{(0)}(2), ..., x^{(0)}(n)\}$

一次累加（1-AGO）：$X^{(1)}(k) = \sum_{i=1}^{k} x^{(0)}(i)$

> 累加的作用：把无规律的序列变成单调增长的序列——灰色系统建模的核心操作。

### 2. 紧邻均值序列

$$Z^{(1)}(k) = 0.5 \cdot x^{(1)}(k) + 0.5 \cdot x^{(1)}(k-1), \quad k=2,3,...,n$$

### 3. 建立灰微分方程

$$x^{(0)}(k) + a \cdot Z^{(1)}(k) = b$$

白化微分方程：

$$\frac{dx^{(1)}}{dt} + a \cdot x^{(1)} = b$$

### 4. 参数估计——最小二乘法

$$\begin{bmatrix} a \\ b \end{bmatrix} = (\mathbf{B}^T \mathbf{B})^{-1} \mathbf{B}^T \mathbf{Y}$$

其中：
$$\mathbf{B} = \begin{bmatrix} -Z^{(1)}(2) & 1 \\ -Z^{(1)}(3) & 1 \\ \vdots & \vdots \\ -Z^{(1)}(n) & 1 \end{bmatrix}, \quad \mathbf{Y} = \begin{bmatrix} x^{(0)}(2) \\ x^{(0)}(3) \\ \vdots \\ x^{(0)}(n) \end{bmatrix}$$

### 5. 预测公式

$$\hat{x}^{(1)}(k+1) = \left(x^{(0)}(1) - \frac{b}{a}\right) e^{-ak} + \frac{b}{a}$$

还原：

$$\hat{x}^{(0)}(k+1) = \hat{x}^{(1)}(k+1) - \hat{x}^{(1)}(k)$$

## Python 实现

```python
import numpy as np

def gm11(x0, predict_n=3):
    """x0: 原始序列, predict_n: 预测步数"""
    n = len(x0)
    x1 = np.cumsum(x0)  # 一次累加

    # 紧邻均值
    Z = np.zeros(n-1)
    for i in range(1, n):
        Z[i-1] = 0.5 * x1[i] + 0.5 * x1[i-1]

    # 最小二乘参数估计
    B = np.column_stack([-Z, np.ones(n-1)])
    Y = x0[1:]
    a, b = np.linalg.inv(B.T @ B) @ B.T @ Y

    # 发展系数 -a，灰色作用量 b

    # 预测
    total = n + predict_n
    x1_pred = np.zeros(total)
    x1_pred[0] = x0[0]
    for k in range(1, total):
        x1_pred[k] = (x0[0] - b/a) * np.exp(-a*k) + b/a

    # 还原
    x0_pred = np.zeros(total)
    x0_pred[0] = x0[0]
    for k in range(1, total):
        x0_pred[k] = x1_pred[k] - x1_pred[k-1]

    return x0_pred[n:], (a, b)
```

## 精度检验

| 检验 | 公式 | 合格标准 |
|------|------|------|
| 残差检验 | $\varepsilon(k) = \frac{|x^{(0)}(k) - \hat{x}^{(0)}(k)|}{x^{(0)}(k)}$ | 平均 < 0.1 |
| 后验差比 | $C = S_2/S_1$（残差标准差/原始序列标准差） | C < 0.35 好，C < 0.5 合格 |
| 小误差概率 | $P = P(|\varepsilon(k) - \bar{\varepsilon}| < 0.6745 S_1)$ | P > 0.95 好 |

## 常见陷阱

- 发展系数 $|a| > 2$ 时模型不可用——数据不适合灰色预测
- 4 个点以下——GM(1,1) 是唯一能跑的方法，但精度不高
- 数据有负值——不能直接做累加，需要平移预处
- 只给预测值、不报告级比检验、残差、后验差比或小误差概率
- 用 GM(1,1) 替代时间序列验证；当数据较多或存在明显周期/波动时，应与 ARIMA、指数平滑、回归或基线外推比较
